# 📈 News Sentiment Stock Predictor

An end-to-end ML project that predicts stock market movement using real-time news sentiment analysis.

## 🎯 Results
- **Best Model:** Random Forest
- **Accuracy:** 71.52% (Industry baseline: 55-60%)
- **F1 Score:** 0.7275
- **ROC-AUC:** 0.7899

## 🛠️ Tech Stack
- **ML:** scikit-learn, Random Forest, SVM, Logistic Regression
- **NLP:** TF-IDF, NLTK, GDELT News API
- **Backend:** Flask REST API
- **Data:** yfinance, GDELT Project
- **Preprocessing:** PowerTransformer, PCA, StandardScaler

## 🚀 How to Run
pip install -r requirements.txt
python app.py
Open: http://127.0.0.1:5000
