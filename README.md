## ❓ Problem Statement
Retail traders and analysts struggle to quickly interpret massive volumes of financial news and understand how sentiment impacts short-term stock movement.  
Traditional analysis is slow, subjective, and often misses real-time market signals.

## 💡 Solution Overview
We built an AI-powered system that:
- Collects and processes financial/news text data
- Performs sentiment analysis on headlines/articles
- Combines sentiment signals with market data
- Predicts potential stock movement trends
- Provides a user-friendly interface for quick insights

This helps users make faster, data-driven decisions by turning unstructured news into actionable stock intelligence.

## ⚙️ Setup Instructions

### 1) Clone the Repository
```bash
git clone https://github.com/mainadhakad/news-sentiment-stock-predictor-hackathon.git
cd news-sentiment-stock-predictor-hackathon
```

### 2) Create and Activate Virtual Environment
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Mac/Linux
source venv/bin/activate
```

### 3) Install Dependencies
```bash
pip install -r requirements.txt
```

### 4) Run the Project
```bash
# Example (choose your actual entry point)
python app.py
# or
streamlit run app.py
```

### 5) Open in Browser
- If Flask/FastAPI: `http://127.0.0.1:5000` (or shown port)
- If Streamlit: `http://localhost:8501`
